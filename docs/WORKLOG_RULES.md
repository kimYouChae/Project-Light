# 작업 기록 규칙

기록 파일은 docs/worklog.md 이다. 없으면 만들어. 최신 기록이 아래로 쌓이게 추가만 하고, 기존 기록은 고치지 마.

## 자동으로 기록할 것
- 작업 날짜, 시작·종료 시각 (date 명령으로 확인. 확인 못 하면 "미확인")
- 내가 준 프롬프트 중 기능 단위로 의미 있는 것
- 새로 만든 파일과 수정한 기존 파일 목록 (git status로 확인)
- 에디터 변경 사항: 씬에 추가·수정한 오브젝트, 프리팹 변경, 컴포넌트 설정값, 애니메이터·Addressables 등 인스펙터에서 바꾼 내용
  - 네가 Unity CLI로 바꾼 것은 직접 기록해
  - 내가 에디터에서 직접 바꾼 것은 git diff로 .unity / .prefab / .asset 변경을 확인해서 오브젝트 단위로 기록해. 무엇이 바뀐 건지 판단이 안 되면 "미확인"으로 표시해
- 에디터에서 바꾼 임시값은 "임시값" 항목에 따로 모아서 적어

## 내가 말하면 정리해서 기록할 것
- 내가 "기록해줘" 또는 "메모"라고 하면서 던지는 내용
- 네 결과물에서 틀렸던 것과 내가 고친 것은 "증상 / 원인 / 조치" 형태로 정리해
- 수치를 바꾼 경우 임시값인지 확정값인지 함께 적어

## 기록하지 말 것
- 내가 왜 그렇게 정했는지에 대한 네 추측
- 확인되지 않은 내용 (모르는 건 "미확인"으로 표시)
