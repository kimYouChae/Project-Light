## 1. 체력UI 규칙 확정

| 항목 | 확정 규칙 | 근거 | 상태 |
| --- | --- | --- | --- |
| 등불 칸 | 화면 오른쪽에 세로로 아래→위 쌓기. 칸 수는 최대 체력(기본 10, 넓은 헤일로로 증가·올림), 켜진 칸은 현재 체력. 피해로 꺼지고 회복(빛 조각·전투 종료)으로 켜짐. 최대 체력 증가 시 현재 체력은 유지하고 칸만 증가. 많아지면 칸 크기 축소. 암막과 상관없이 항상 보임 | GDD 체력·상태 표시, Q25 | ✅(확정) |
| 등불 아이콘 | 임시 도형(##TEMP)을 사용하고 나중에 그림으로 교체. 기존 파일 덮어쓰기 금지 | Q26 | ✅(확정) |
| 피격 | 몸이 빨갛게 번쩍이고 실제로 깎인 칸 수를 '-1'/'-2'처럼 몸 위에 띄워 약 0.3초 동안 떠오르며 사라짐. 숫자는 풀링 | GDD 체력·상태 표시, 승인된 계획 | ✅(확정) |
| 피격 후 무적 | 깜빡임. 글자 없음 | GDD 체력·상태 표시 | ✅(확정) |
| 물림 착지 무적 | 깜빡임 | Q23 | ✅(확정) |
| 퍼펙트 무적 | 금색 | GDD 체력·상태 표시 | ✅(확정) |
| 무적 겹침 | 금색 우선. 금색이 끝나면 남은 피격·착지 무적은 깜빡임 | Q24 | ✅(확정) |
| 시간 | 연출은 게임 시간(timeScale)을 따라 보상창이 열려 있으면 멈춤 | 승인된 계획 | ✅(확정) |
| 세부 수치 | 칸 크기·간격, 번쩍임 시간·색, 깜빡임 주기, 금색 정도, 숫자 폰트·색·크기·떠오르는 거리는 Codex ##TEMP 제안, 플레이 후 조정 | Q27 | ✅(확정) |
| 현재 코드 상태 | 무적이 PlayerHealth.invulnerableUntil 하나로만 관리되어 원인 구분 불가. 피격은 ApplyHit, 퍼펙트·물림 착지는 GrantInvulnerability | 현재 코드, 승인된 계획 | ✅(확정) |
